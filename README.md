# Devly Interview Lab

AI-тренажёр технических собеседований для разработчиков. Пользователь выбирает карьерный профиль, проходит интервью из пяти вопросов и получает персональную оценку ответов.

## Возможности

- регистрация и вход через Supabase Auth;
- генерация вопросов с учётом роли, уровня и стека;
- прохождение интервью в диалоговом интерфейсе;
- AI-оценка технической точности, архитектурного мышления и коммуникации;
- сохранение истории интервью и отчётов;
- дашборд, аналитика прогресса, профиль и справочный раздел;
- адаптивный интерфейс для компьютеров и мобильных устройств.

## Стек

- React 19, TypeScript, Vite;
- Tailwind CSS 4;
- Supabase Auth и Supabase Edge Functions;
- OpenAI API (`gpt-4o-mini`);
- Hono для серверных маршрутов.

## Локальный запуск

Требуется Node.js и `pnpm`.

```bash
pnpm install
pnpm dev
```

Для production-сборки:

```bash
pnpm build
```

## Backend

Серверная логика находится в `supabase/functions/server/index.tsx`. Edge Function:

- проверяет JWT пользователя;
- не передаёт OpenAI API-ключ в браузер;
- генерирует вопросы;
- оценивает ответы;
- сохраняет профиль и интервью отдельно для каждого пользователя.

Необходимый секрет Edge Function:

```text
OPENAI_API_KEY
```

Параметры подключённого Supabase-проекта создаются Figma Make в `utils/supabase/info.tsx`. После изменения серверной функции её необходимо повторно развернуть через настройки Supabase в Figma Make.

## Безопасность

- реальные секреты не хранятся в репозитории;
- OpenAI вызывается только на сервере;
- все пользовательские запросы к данным требуют действующую Supabase-сессию;
- приложение не предназначено для хранения паспортных, платёжных или других чувствительных персональных данных.
